# JARVIS Android

Assistente pessoal inteligente para Android.

## Fase 1
Base inicial em Kotlin + Jetpack Compose, separando UI, estado, cérebro e ferramentas.

UI -> Orchestrator/ViewModel -> BrainProvider -> ToolRouter -> Android OS

O projeto não utiliza VPS ou servidor intermediário obrigatório. Nenhuma API key é incluída no código-fonte.

## Próximas fases
Gemini/streaming -> Room/DataStore -> ferramentas Android -> Accessibility -> voz -> multimodalidade -> notícias/imagens -> WhatsApp -> memória/segurança/testes.
